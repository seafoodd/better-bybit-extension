# Bybit P2P Order Highlighter (Firefox Extension)

Расширение для **Firefox**, которое автоматически подсвечивает P2P-объявления на **Bybit** по ключевым словам: **«СБП»**, **«телефона»** (и любым другим, заданным пользователем).

---

## 🎯 Какую проблему решает?

На Bybit P2P (особенно в секциях RUB / USDT / др.) продавцы часто выставляют объявления под общими способами оплаты (например, *«Mobile Top-up»*, *«Cash Deposit to Bank»* или *«Bank Transfer»*), а свои реальные условия пишут в примечании (**`remark`** в API):
> *«🟢 ВАЖНО! ОПЛАТА ТОЛЬКО ЧЕРЕЗ СБП ПО НОМЕРУ ТЕЛЕФОНА...»*

В стандартном интерфейсе Bybit это примечание скрыто: чтобы его прочесть, приходится нажимать «Купить» на каждом объявлении по очереди.

**Это расширение:**
1. **Перехватывает ответы P2P API Bybit** (`/fiat/otc/item/online`) на лету.
2. **Проверяет условия сделки (`remark`) и текст строки** на наличие ключевых слов (**«СБП»**, **«телефона»** и др.).
3. **Мягко подсвечивает подходящие строки** красивым изумрудным градиентом и рамкой.
4. **Выводит бейдж `⚡ СБП`** прямо в строке объявления.
5. **Показывает примечание продавца прямо в таблице** с выделением совпавших слов (`<mark>СБП</mark>`) и кнопкой разворачивания.
6. **Добавляет плавающий счетчик** на страницу (`⚡ 4 / 10 СБП`) с быстрыми кнопками фильтрации.

## 🚀 Сборка и установка

### Требования
* **Node.js** (v18+)
* **pnpm** (или npm / yarn)

### Установка зависимостей и сборка
```bash
# Установка зависимостей
pnpm install

# Проверка типов
pnpm compile

# Сборка для Firefox (Manifest V3)
pnpm run build:firefox

# Или сборка для Chrome / Chromium (Manifest V3)
pnpm run build
```

Собранные файлы расширения появятся в каталоге `.output/firefox-mv3` или `.output/chrome-mv3`.

---

### Загрузка в браузер

#### Firefox
1. Откройте страницу `about:debugging#/runtime/this-firefox` в браузере.
2. В секции **Временные расширения** нажмите **«Загрузить временное дополнение…»** (Load Temporary Add-on).
3. Выберите файл `.output/firefox-mv3/manifest.json` (или собранный `.zip` архив из папки `.output`).

#### Chrome / Chromium (Яндекс.Браузер, Edge, Brave)
1. Откройте `chrome://extensions` и включите **«Режим разработчика»** (Developer mode).
2. Нажмите **«Загрузить распакованное расширение»** (Load unpacked).
3. Укажите папку проекта: `.output/chrome-mv3`.

## ⚙️ Возможности и Настройки (Popup)

Нажмите на иконку расширения `⚡` на панели инструментов Firefox:

* **Главный переключатель**: Включение / отключение подсветки в один клик.
* **Список ключевых слов**:
  * По умолчанию: `СБП`, `телефона`.
  * Добавление любых новых слов (например, `Тинькофф`, `Сбер`, `Т-Банк`, `Озон`, `Райф`, `QR`).
  * Удаление ненужных слов нажатием на крестик `×`.
  * Быстрые чипы для добавления популярных банков в один клик.
* **Цветовые темы**:
  * 🟢 **Изумрудный** (Emerald) — по умолчанию, идеален для тёмной и светлой темы Bybit.
  * 🟡 **Золотой / Янтарный** (Amber / Bybit Gold).
  * 🔵 **Неоновый Циан** (Electric Cyan).
  * 🟣 **Фиолетовый** (Neon Violet).
* **Параметры отображения**:
  * *Показывать примечание (remark) в строке* — выводит текст условий сделки прямо под строкой ордера.
  * *Затемнять остальные заказы* — делает неподходящие строки полупрозрачными.
  * *Скрывать остальные заказы* — оставляет на странице только ордера с СБП / телефоном.

## 📁 Архитектура и структура проекта

Проект разработан на **TypeScript** с использованием фреймворка **[WXT](https://wxt.dev/)**:

```text
better-bybit/
├── entrypoints/
│   ├── content/               # Точка входа Content Script
│   │   ├── index.ts           # Инициализация и координация сервисов
│   │   └── style.css          # Стили подсветки, тегов и бейджей
│   ├── injected.content.ts    # Main-world скрипт перехвата XHR/Fetch API Bybit
│   └── popup/                 # Всплывающее окно настроек расширения
│       ├── index.html
│       ├── main.ts
│       └── style.css
├── src/
│   ├── constants/             # Селекторы DOM и конфигурация
│   ├── content/               # Модули анализа и модификации страницы
│   │   ├── amountInput.ts     # Автозаполнение суммы кликом по числам
│   │   ├── observer.ts        # Наблюдатель за DOM и перерисовка таблицы
│   │   ├── orderHighlighter.ts# Логика подсветки строк и бейджей
│   │   ├── orderMatcher.ts    # Сопоставление данных API с элементами DOM
│   │   ├── pageDetector.ts    # Определение активного типа страницы
│   │   └── paymentSelector.ts # Управление фильтрами способов оплаты
│   ├── services/              # Хранилище настроек (Storage) и OTC Store
│   ├── types/                 # TypeScript интерфейсы и контракты данных
│   └── utils/                 # Утилиты обработки DOM, чисел и текста
├── public/                    # Статические иконки и ассеты
├── wxt.config.ts              # Конфигурация WXT (манифест MV3, разрешения)
└── package.json
```

## 🔄 Как работает автообновление?

* При включенном на Bybit таймере **«5s Refresh»** или переходе по страницам расширение автоматически перехватывает новые пакеты данных и обновляет подсветку без задержек.
* При изменении ключевых слов в окне расширения подсветка на открытой вкладке Bybit обновляется мгновенно без перезагрузки страницы.
